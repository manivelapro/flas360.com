# Flas360.com — Estrutura GitHub Pages

Este pacote foi organizado para publicação direta no **GitHub Pages** a partir da branch `main` (pasta raiz `/`).

## Estrutura de Pastas

- `(raiz)/`
- `2026/11/`
- `assets/css/`
- `assets/js/`
- `p/`

## Como publicar no GitHub Pages

1. Crie um novo repositório no GitHub (ex.: `meu-site`).
2. Envie todos os arquivos e pastas deste pacote mantendo exatamente a hierarquia (`index.html` na raiz, pastas `assets/`, `p/`, etc.).
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment → Source**, selecione **Deploy from a branch**.
5. Escolha a branch **main** e a pasta **/ (root)** e clique em **Save**.

## Domínio personalizado (CNAME)

O arquivo `CNAME` está configurado para `www.flas360.com`. Caso queira usar o endereço padrão `usuario.github.io/repositorio`, remova o arquivo `CNAME`.
